# Chronoforge

Editor tool for authoring RTS build orders fast. Create a `BuildOrderAsset`
(right-click in Project window → `Create > Chronoforge > Build Order`) and use
the custom inspector to add, reorder, and export steps without leaving the
Inspector.

- Quick-add buttons per step type (Unit / Building / Upgrade / Note), each
  pre-filling supply and time from the previous step.
- Inline supply / time (`MM:SS`) / type / action editing per row, drag to
  reorder.
- Sort by supply, export to plain text or JSON.
